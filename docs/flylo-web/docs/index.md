# FlyLo Web

Public marketing and booking-entry website for **FlyLo Air** — “the quiet way to fly.”

| **Stack** | TypeScript · Next.js |

## What it does

- Brand homepage, route network, and cabin products (Atlas / Prospect / Linen)
- Deep links into booking on [book.flylo-air.com](https://book.flylo-air.com/)
- Primary surface for Cursor + Backstage demos (Malmö workshop)
