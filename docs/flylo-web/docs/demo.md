# Demo notes (Malmö)

1. Open **Catalog → FlyLo Web** in Backstage
2. Show **About** (owner, system, depends-on, APIs)
3. Open **GitHub** link → [voxic/flylo-web](https://github.com/voxic/flylo-web)
4. Optional: live site [www.flylo-air.com](https://www.flylo-air.com/)
5. Pair with Cursor on the `web` repo for agentic coding

TechDocs for this component are served from the Progress42 Backstage catalog repo (local builder), not cloned from the private app repo — so docs stay available without a GitHub App token.
